Ishani AI 3.0 update
====================

Files:
- client/src/App.jsx
- client/src/App.css
- client/public/ishani.png

Install these into your existing project by replacing the matching App.jsx and App.css,
and copying ishani.png into client/public/.

WhatsApp:
- The bottom contacts panel has been removed.
- To prepare a WhatsApp message, type:
  WhatsApp 919876543210: Your message here
- Use country code and digits only in the phone number.
- This opens a WhatsApp click-to-chat draft. It does NOT read your WhatsApp contacts,
  inspect chats, or send messages automatically. Review and press Send yourself.

Limitations:
- This is an offline rule-based assistant, not a general AI model. The response bank
  includes more keyword-based replies, but cannot reliably answer every new question.
- Voice recognition depends on browser support and microphone permission.
